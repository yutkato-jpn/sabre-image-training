# ⚔ Sabre Mind — サーブル・イメージトレーニングアプリ

サーブル(フェンシング)選手のための、科学的根拠に基づくイメージトレーニング用Webアプリです。
インストール不要・完全無料・データは端末内にのみ保存されます。

**公開URL: https://yutkato-jpn.github.io/sabre-image-training/**
(mainブランチへのマージ後、GitHub Actionsが自動でデプロイします)

## 📱 スマホでアプリとして使う

1. スマホのブラウザで上のURLを開く
2. **iPhone (Safari)**: 共有ボタン → 「ホーム画面に追加」
3. **Android (Chrome)**: メニュー → 「ホーム画面に追加」

ホーム画面から起動すると全画面のアプリとして動きます。一度開けばオフラインでも使えます(YouTube再生を除く)。

## 機能

| タブ | 内容 |
|---|---|
| 🧠 **イメトレ** | 音声ガイド付きイメージトレーニング。入門(イメージ力ブートキャンプ)/技術/戦術・先読み/メンタル/クイックの5カテゴリ、プリセット17本+自作可能 |
| ⚡ **先読み** | 「相手がこう動いたら次は?」の場面クイズ30問+自作問題。予測のパターン辞書を作る |
| 🎬 **動画** | YouTube動画を登録して、決着直前で止めて続きを予測する**オクルージョン(時間遮蔽)訓練**と観察イメトレ |
| 📈 **記録** | 週間目標(週3〜4回)、鮮明度・コントロール度の推移グラフ、週間トレーニング時間 |
| ⚙ **設定** | 音声速度、パーソナライズ(自分の剣・会場・得意技をスクリプトに差し込み)、データのバックアップ |

## 🔬 科学的根拠(要約)

- **量**: 1回10〜15分・週3〜4回が最適域([メタ分析](https://link.springer.com/article/10.1007/s40279-018-0874-8))。フェンシング選手の実験では[1分のイメージ直後に突きの的中+25.5%・ファント(ランジ)距離+11.1%](https://www.mdpi.com/2076-3425/15/12/1338)
- **質**: 一人称・実速度・身体感覚込み([PETTLEP](https://www.mdpi.com/2076-3417/12/19/9753))。自分で作り込んだスクリプトほど効果が高い
- **予測力**: 反応0.2秒の壁は予測で超える。熟練者は[体幹と武器腕の早期の動き](https://www.frontiersin.org/journals/sports-and-active-living/articles/10.3389/fspor.2024.1387013/full)を読む。[時間遮蔽訓練は予測力を向上させ実戦に転移する](https://link.springer.com/article/10.1007/s40279-024-02073-6)

詳細はアプリ内の「🔬 なぜイメトレで強くなれるのか」を参照。

## 開発

ビルド不要の静的サイト(vanilla JS)です。

```bash
# ローカルで動かす
python3 -m http.server 8000
# → http://localhost:8000
```

- データ保存: localStorage(設定画面からJSONで書き出し/読み込み可能)
- 音声: Web Speech API(日本語TTS)、非対応環境はチャイム+テキストで動作
- 動画: YouTube IFrame Player API(APIキー不要)
- デプロイ: `.github/workflows/pages.yml` が main への push で GitHub Pages に自動デプロイ

> ⚠ 戦術ドリルの「正解」は一般的なセオリーです。所属コーチの指導と異なる場合はコーチを優先してください。
